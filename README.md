# MMD Auto Tools V1.0.0

**Blender MMD 视频自动化制作插件｜社区测试版（Beta）**

MMD Auto Tools 是一款用于 Blender 的 Python 插件，旨在将 PMX/PMD 模型、VMD 动作、摄像机动画、物理烘焙、场景渲染与视频编码整合到一个工作流程中，减少重复操作。

> **AI 辅助生成声明：本项目代码由 ChatGPT 模型辅助生成，并在用户提出需求、指导功能设计和迭代测试的过程中逐步完善。** 使用 AI 辅助开发不代表 OpenAI 对本项目进行官方认证、维护或担保。本项目并非 OpenAI 官方产品。

## 功能

- 导入 PMX / PMD 模型与 VMD 动作，支持独立 VMD 摄像机文件。
- 根据动作设置动画帧范围，并处理 VMD 起始帧姿势。
- 调用 MMD Tools 构建物理系统，支持渲染前自动烘焙及手动烘焙。
- **原背景合成**：渲染透明人物，支持静态图片或视频背景，并合成音频。
- **三维舞台**：支持圆形或方形平台、脚底高度估算、平台材质和灯光。
- 支持单个视频制作与按文件名匹配动作、音频、镜头的批量制作。
- 支持设置分辨率、帧率、模型/动作缩放、预览图和输出路径。
- 使用外部 FFmpeg 进行视频编码及音频合成。

## 安装

1. 在 Blender 中安装并启用兼容版本的 **MMD Tools**。
2. 自行安装 **FFmpeg**，建议将其所在目录加入系统 `PATH`。在终端运行 `ffmpeg -version` 可初步检查是否可用。
3. 打开 Blender，进入 **编辑（Edit）→ 偏好设置（Preferences）→ 插件（Add-ons）**，使用适用于当前 Blender 版本的“从磁盘安装”功能，选择插件 `.py` 文件或发行 ZIP。
4. 启用 **MMD Auto Video** 插件。
5. 在 **3D 视图 → 侧边栏（N）→ MMD Auto** 找到操作面板。
6. 点击 **检查环境**，确认模型路径和外部依赖等配置。

> Blender 不同版本的插件安装界面可能不同。如果 ZIP 安装失败，可先解压并尝试安装其中的 `.py` 文件。

## 快速开始

### 单个视频

1. 选择 **模型**（`.pmx` / `.pmd`）、**动作**（`.vmd`）和**音频**文件。
2. 可选：指定独立 **镜头 VMD**；如动作文件包含镜头数据，可按实际情况留空。
3. 选择输出模式：
   - **原背景合成**：可指定图片或视频背景；不指定背景时使用透明视频输出流程。
   - **三维舞台**：可调整平台形状、尺寸、高度、颜色、粗糙度和金属度。
4. 设置输出目录、分辨率、FPS 等参数。
5. 建议保留 **渲染前自动物理烘焙**，点击 **生成视频**。

### 批量生成

1. 设置模型路径及 **动作文件夹**。
2. 可选：设置 **音频文件夹**、**镜头文件夹**。
3. 插件按文件名匹配对应资源；请提前整理文件名并检查匹配结果。
4. 点击 **开始批量生成**。

## 输出文件

插件会根据输出模式生成相应文件，通常包括：

- `*_MMD_Auto.mp4`：合成或三维舞台模式下的视频。
- `*_MMD_Auto_Transparent.mov`：透明视频中间文件（适用时）。
- `*_MMD_Auto_Transparent_Audio.mov`：无背景时的透明视频与音频合成文件（适用时）。
- `*_MMD_Auto.blend`：保存的 Blender 工程。
- `*_MMD_Auto.json`：本次制作的参数记录。
- `*_MMD_Auto_preview.png`：启用预览时生成的图片。
- `*_MMD_Auto_RGBA_Frames/`：逐帧渲染文件目录。

具体文件以所选模式和实际执行结果为准。渲染可能消耗较多时间和磁盘空间。

## 使用提示与已知限制

- **VMD Margin 建议保持 `0`**，以避免起始帧出现非预期姿势。
- 不同 PMX 模型、VMD 动作和 MMD Tools 版本可能存在兼容性差异。
- 物理烘焙性能受模型复杂度、碰撞体、Blender 设置和硬件影响。
- 三维舞台的**粗糙度**与**金属度**只控制材质外观，不保证产生清晰的人物镜面倒影。
- 本版本为社区测试版；尚未宣称通过所有 Blender 版本、模型和操作系统的全面测试。
- 请在正式制作前先用短动画测试，并备份重要工程文件。
